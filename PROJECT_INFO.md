## О проекте

**SolRes (Сольрес)** — искусственный язык, кодирующий смысл через музыкальные интервалы вместо фонетики. 
Алфавит: 7 нот (До, Ре, Ми, Фа, Соль, Ля, Си). Слова: комбинации интервалов между нотами. 
Грамматика: фиксированный порядок 12 категорий примитивов (размер → физика → материал → форма → цвет → действие → отношение → оценка → количество → пространство → время).

## Структура проекта
```
solres_language/
├── core/ # Ядро: ноты, интервалы, синтез звука
│ ├── constants.py # 7 нот, 13 интервалов, направления
│ ├── interval_calculator.py # Конвертация нот в MIDI/частоты
│ └── synthesizer.py # Генерация звука (синусоиды, пианино)
│
├── language/ # Лингвистика
│ ├── primitives.py # 135+ семантических примитивов в 12 категориях
│ ├── descriptors.py # Дескриптивная грамматика (слова = описания)
│ ├── lexicon.py # Старый словарь (не используется)
│ └── grammar.py # Старая грамматика (не используется)
│
├── chords/ # Аккордовая система
│ └── chords.py # Аккорды как мгновенные слова
│
├── web/ # Веб-интерфейс
│ └── app.py # Flask приложение (мобильная версия + слайдер скорости)
│
├── evolution/ # Эволюция языка
│ ├── proposal.py # Структура предложений
│ ├── version_control.py # Голосование и версионирование
│ └── review.py # Система модерации (только создатель одобряет)
│
├── tests/ # Тесты
├── utils/ # MIDI-экспорт
├── proposals/ # Предложения сообщества (.json)
├── backups/ # Резервные копии перед изменениями
├── midi_output/ # Сгенерированные .mid файлы
├── README.md # Документация (EN/RU)
├── requirements.txt # Зависимости для разработки
└── requirements_web.txt # Зависимости для веб-сервера
```
