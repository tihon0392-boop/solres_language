## 🇬🇧 English

**SolRes** encodes meaning through **musical intervals** — distances between notes — instead of phonetics.

### Why It Works
- **Notes are identical worldwide** — C is C in Russia, China, Brazil
- **Intervals are physics** — a major third is 5:4 frequency ratio everywhere
- **Direction = grammar** — up = light/active, down = dark/passive
- **Community-driven** — propose words, vote, evolve on GitHub Discussions

### Features
- 🔍 **Translate** — type a word, hear its melody
- 🧩 **Compose** — build words from 135+ primitives in 12 categories
- 🎸 **Instruments** — play piano, analyze intervals, save melodies
- 📝 **My Words** — save your custom words (localStorage)
- 💬 **Sentences** — chain words into sentences with drag & drop
- 📄 **Text** — build text from sentences, reorder, play all
- 📖 **Dictionary** — browse all primitives and words
- ⚡ **Speed control** — slow down or speed up playback

### Quick Start
```bash
git clone https://github.com/tihon0392-boop/solres_language.git
cd solres_language
pip install flask numpy sounddevice
python web/app.py
```
## 🇷🇺 Русский

**Сольрес** — язык, кодирующий смысл через **музыкальные интервалы**.

### Почему это работает
- **Ноты одинаковы во всём мире** — До везде До
- **Интервалы — физика** — мажорная терция = 5:4 для всех культур
- **Направление = грамматика** — вверх = свет, вниз = тьма
- **Сообщество** — предлагайте слова, голосуйте на GitHub Discussions

### Возможности
- 🔍 **Translate** — введите слово, услышите мелодию
- 🧩 **Compose** — составьте слово из 135+ примитивов
- 🎸 **Instruments** — пианино с анализом интервалов
- 📝 **My Words** — сохраняйте свои слова
- 💬 **Sentences** — составляйте предложения
- 📄 **Text** — тексты из предложений
- ⚡ **Контроль скорости** — замедляйте и ускоряйте
